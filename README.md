# 畫委託需求整理所

作者：懧雃

免安裝的靜態網站，一步一步整理繪圖委託需求、上傳角色和其他參考圖，並輸出文字、長圖 PNG 或可預覽分頁的 PDF。

## 使用流程

1. 基本資訊：委託類型、用途、預算、交期
2. 角色：名稱、外觀、服裝與設定圖（可新增、複製角色）
3. 畫面：情境構圖、姿勢互動、背景與畫風
4. 交付：尺寸、格式、注意事項與其他參考圖
5. 完成：預覽訊息後選一種方式傳給繪師
   - 複製文字：貼到私訊
   - 存成圖片：文字和參考圖自動排版成圖片（適合社群私訊、Discord、LINE）
   - 存成 PDF：自動分頁的一份文件，參考圖以原始解析度嵌入、不會模糊（適合 Email）
   - 傳送原圖：手機直接分享文字和原始參考圖；電腦下載 ZIP（文字檔＋原圖）

委託外國繪師時，可以在第 5 步打開「用 AI 翻譯成其他語言」：按「複製翻譯指令」貼到 ChatGPT、Gemini 或 Claude（都有免費方案），把翻譯結果貼回來，之後複製文字、存成圖片、PDF、傳送原圖都會改用翻譯後的文字，參考圖也會放回各自角色的位置。

常用的角色可以按角色卡片上的「存到角色庫」（文字和設定圖一起存），下次委託在第 2 步按「從角色庫帶入」即可。角色庫只存在這台裝置，清除草稿不會刪除。換裝置或分享給朋友時，可以在角色庫裡「匯出」成角色檔（.json，含設定圖），再到另一台裝置「匯入」；也可以直接匯入委託備份檔，取出裡面的角色。

參考圖按「＋ 加入圖片」即可加入，電腦也可以拖曳或直接貼上（Ctrl+V）。所有排版都是自動的，不需要調整圖片大小或分頁。

## 上傳至 GitHub

1. 將這個 ZIP 解壓縮。
2. 將解壓後的 `index.html`、`export.js`、`draft.js`、`library.js`、`apple-touch-icon.png`、`.nojekyll` 和 `README.md` 上傳到儲存庫最外層（更新時直接覆蓋舊檔，使用者原本的草稿不受影響）。
3. 在儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**，設定 `main` 分支及 `/ (root)` 資料夾後儲存。

草稿保存在使用者自己的瀏覽器（文字使用 localStorage、圖片使用 IndexedDB），不會上傳到網站，也不會在不同裝置間同步；需要換裝置時請使用「匯出備份檔」。
