# 畫委託需求整理所

免安裝的靜態網站，用來整理繪圖委託需求、上傳角色和其他參考圖，並輸出文字、長圖 PNG 或可預覽分頁的 PDF。

## 主要功能

- 填寫委託資料，即時產生可一鍵複製的委託訊息（開頭問候與結尾可自訂）
- 每位角色可上傳設定圖，複製文字時會自動註明「另附 N 張」
- 「複製角色」可快速建立設定相近的角色
- 電腦版可直接把圖片拖曳到上傳框
- 匯出長圖片 PNG（內容很長時會自動分成多張）或 A4 PDF（可調整分頁，分頁不會切到文字）
- 草稿自動保存在本機瀏覽器；「匯出備份檔／匯入備份檔」可換裝置繼續編輯或保存每次委託
- 手機版下方有固定的「複製訊息」與「看預覽與匯出」按鈕
- 支援 iPhone「加入主畫面」圖示

## 上傳至 GitHub

1. 將這個 ZIP 解壓縮。
2. 建立一個 GitHub repository，將解壓後的 `index.html`、`export.js`、`draft.js`、`apple-touch-icon.png`、`.nojekyll` 和 `README.md` 上傳到儲存庫最外層。請上傳解壓後的檔案，不要只上傳 ZIP 本身。（更新舊版時，直接用新檔案覆蓋即可，使用者原本的草稿不受影響。）
3. 若要公開成網站，在儲存庫的 **Settings → Pages**，選擇 **Deploy from a branch**，設定 `main` 分支及 `/ (root)` 資料夾，再儲存。
4. 等待 GitHub Pages 完成發布後，即可使用顯示的網址。

也可以直接在瀏覽器開啟 `index.html` 使用。草稿保存在使用者自己的瀏覽器（文字使用 localStorage、圖片使用 IndexedDB），不會上傳到網站，也不會在不同裝置間同步；需要換裝置時請使用「匯出備份檔」。圖片檔只在使用者選取後於瀏覽器中處理。
